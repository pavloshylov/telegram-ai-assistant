# Returns and warranty

## Returns
You can return any product within 30 days of delivery, for any reason, if it is complete and undamaged.
Return shipping is free for orders in the EU: request a return label in this chat or by email.
We refund the money to the original payment method within 5 working days after the parcel arrives.
For hygiene reasons in-ear earbuds can be returned only if the sealed ear tips are unopened.

## Warranty
All products have a 2-year warranty. Premium headphones (marked "3-year warranty" in the catalog) have 3 years.
The warranty covers manufacturing defects, not drops, water damage beyond the IP rating, or worn ear pads.
For a warranty claim, send the order number and a short video of the problem; we reply within 1 working day.
